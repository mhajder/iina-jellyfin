Jellyfin for IINA

Browse your Jellyfin server inside IINA and play its movies, shows and music directly, with titles, subtitles, progress and next episodes handled for you.

Getting started

  1. Open the Jellyfin browser: Plugin → Show Jellyfin Browser (⌘⇧J), or the Jellyfin tab in the player's sidebar.
  2. Click Add Server and enter your server URL, for example http://192.168.1.100:8096.
  3. Sign in with your username and password, or use Quick Connect and approve the code from another Jellyfin app.

Opening a Jellyfin link that contains an API key (such as a download link) also adds that server and signs you in, unless Sign in from Jellyfin links is turned off.

Browsing and playing

Pick a movie, episode or song to play it. Search, Continue Watching, your libraries, favorites and music albums are all in the browser; playing an album queues all of its tracks.

By default each video opens in a new IINA window so you can keep browsing. Turn off Open media in a new IINA window to play in the current one.

You can add several servers and switch between them in the browser. Logging out removes that server; you will need its URL and credentials to add it again.

While a Jellyfin video plays

Each of these can be turned off in the plugin's settings:

  • Title: the window shows the Jellyfin title, not the stream's file name.
  • Progress: playback resumes where you left off, your position is sent to Jellyfin every 10 seconds, and the item is marked watched at 95%.
  • Next episode: the next episode is queued and starts when the current one ends, continuing into the next season.
  • Audio and subtitles: the audio in your most preferred language is selected. Subtitles are turned on only when you prefer another language over the audio's.
  • Subtitle files: the item's external subtitle files in your preferred languages are downloaded. Subtitles inside the video file are already available in IINA.

Plugin menu

Under Plugin in the menu bar, in the Jellyfin section:

  • Download Jellyfin Subtitles: download the subtitle files again.
  • Set Jellyfin Title: fetch the title again.
  • Show Jellyfin Browser (⌘⇧J): open the browser.
  • Jellyfin Version: only for items with several versions in Jellyfin (for example 4K and 1080p). Switches version and keeps your position.

Opening Jellyfin links directly

Links opened in IINA some other way (Open URL, a browser extension, Syncplay) get the same handling when they point at a Jellyfin item and carry an API key, for example:

  • https://server/Videos/{ItemId}/stream?static=true&ApiKey={key}
  • https://server/Items/{ItemId}/Download?ApiKey={key}

Servers behind a reverse-proxy path, such as https://example.com/jellyfin, work too.

Troubleshooting

No subtitles were downloaded

Only external subtitle files are downloaded, and only in your preferred languages. Check the language codes in the settings, or turn on Download subtitles in every language. Subtitles embedded in the file are in IINA's Subtitles menu.

The wrong audio or subtitle track is selected

Put your languages in order of preference, most preferred first. A preferred language set in IINA's own Audio or Subtitles settings takes precedence over the plugin. To keep the file's own default tracks, turn off Pick audio and subtitles in my languages.

Progress does not show up in Jellyfin

Check that Sync playback progress with Jellyfin is on. Progress goes to the account whose API key is in the link, unless Report to my signed-in account is on.

Reporting a problem

Turn on Debug logging in the plugin's settings and logging in IINA's Advanced settings, reproduce the problem, then open an issue at github.com/mhajder/iina-jellyfin with the log attached. API keys and tokens are removed from the plugin's logs.
