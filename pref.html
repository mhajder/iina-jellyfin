Playback

Play what you pick in the Jellyfin browser in a separate window, so you can keep browsing. Turn off to play in the current window.

Show the movie or episode title from Jellyfin instead of the file name from the stream URL.

While an episode plays, queue the next one in the series, continuing into the next season, so it starts when the current one ends.

Languages & Subtitles

Comma-separated, most preferred first, e.g. pol,eng. 2- and 3-letter codes both work (en and eng mean the same language). Used for the subtitle downloads and the track selection below.

When playback starts, switch to the audio in your most preferred language, never a commentary or audio description. Unless Always show subtitles is on, subtitles are turned on only when the audio is not in a language you rank higher; otherwise only a signs/songs track in the audio's language is used, if there is one.

A preferred audio or subtitle language set in IINA's own settings takes precedence.

Also turn on full subtitles in the audio's own language. Subtitles in a language you rank below the audio's stay off. Needs the option above, and has no effect when a preferred subtitle language is set in IINA's own settings.

When Jellyfin media opens, download its external subtitle files in your preferred languages. Subtitles inside the video file need no download; IINA reads them directly.

Ignore the preferred languages when downloading external subtitles.

Progress & Account

Resume where you left off, report your position to Jellyfin every 10 seconds, and mark items watched at 95%.

Record progress and watched status in the account you signed into in the Jellyfin browser, instead of the account whose API key is in the playing link. Useful with Syncplay: everyone opens the same link, and each viewer's progress goes to their own account. Falls back to the link's key when you are not signed in to that server.

When you open a Jellyfin link that contains an API key (such as a download link), save that server so the Jellyfin browser signs in automatically. Saved servers stay until you remove them in the browser.

Notifications & Troubleshooting

Show an on-screen message when subtitles are downloaded, when none match, or when the download fails.

Write detailed logs (requests, URL parsing, track choices) to IINA's log for troubleshooting and bug reports. API keys and tokens are removed from the logs.
